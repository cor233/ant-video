Node 服务型小程序

drpy-node / drpyS

服务由宿主按需启动。下面两个地址是对外使用的主要接口，可直接复制到宿主的影视源或猫源配置中。

通用影视接口

返回完整影视站点配置，适合影视源/T4 配置入口。

宿主内部逻辑地址 miniapp://com.leospring.drpy_node/config/1?healthy=1

猫源接口

用于 CatPaw/猫影视兼容客户端的在线 DS 猫源入口。

宿主内部逻辑地址 miniapp://com.leospring.drpy_node/config/index.js.md5

局域网对外共享

在小程序详情页开启“局域网共享”后，把宿主显示的共享基址分别拼接：

<共享基址>/config/1?healthy=1 <共享基址>/config/index.js.md5

共享令牌就是访问凭证，请勿在公共网络泄露。当前包默认关闭 drpy 自身 Basic Auth，以便 miniapp:// 地址直接使用。

其他接口

健康检查：miniapp://com.leospring.drpy_node/health
单源 API：miniapp://com.leospring.drpy_node/api/<源名称>
