Node 服务示例

这个页面只是占位——本小程序的主要价值在包内的 server/ 目录： 宿主会用内嵌 node 把它作为独立 worker 跑起来。

验证方法
  1. 在小程序详情页点「启动」，状态会显示 运行中 · 端口 NNNN
  2. 浏览器或 curl 访问 127.0.0.1:NNNN/hello（curl 默认走 http）
  3. 或者在任何认 miniapp:// 地址的设置里填 miniapp://com.leospring.node_demo/api/time， 宿主会自动拉起本服务再转发请求
服务端接口
  • GET /check — 就绪探测（宿主启动时轮询的就是它）
  • GET /hello — 返回 index.config.js 里配置的问候语与进程 pid
  • GET /api/time — 返回当前时间与 node 版本
