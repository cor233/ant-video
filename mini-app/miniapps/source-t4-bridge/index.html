接口路径

下面是业务路径，前面接上当前地址前缀 miniapp://com.leospring.source_t4_bridge；站点既能写成 /site/mock_cms，也能写成 ?site=mock_cms。key 就是宿主采集源的 key。

GET /site/站点key?filter=true首页与分类（宿主 classes → T4 class）
GET /site/站点key?t=分类ID&ac=videolist&pg=1分类列表，T4 的 ext 原样传给宿主
GET /site/站点key?wd=关键词&pg=1搜索
GET /site/站点key?ac=detail&ids=影片ID详情，多个 ID 用逗号分隔
GET /site/站点key?flag=线路&play=集地址播放，爬虫源由宿主解析后返回直链
GET /?ac=videolist&t=1省略站点，走默认站点
GET /config多站点配置，可用 ?base= 指定返回的前缀
GET /health服务状态与站点数量
