LogVar 弹幕服务 · Node 版

弹幕服务本体跑在宿主内嵌 Node 里，本页提供对外引用地址

对外地址

主地址 —— 弹弹play 兼容播放器的弹幕 API 填这个
miniapp://com.logvar.danmu.node
Fongmi / 影视
miniapp://com.logvar.danmu.node/api/v2/fongmi/danmaku
匹配接口（调试用）
miniapp://com.logvar.danmu.node/api/v2/match
弹幕获取（调试用，需拼 episodeId）
miniapp://com.logvar.danmu.node/api/v2/comment
搜索剧集（调试用）
miniapp://com.logvar.danmu.node/api/v2/search/episodes

怎么用

  1. 播放器 → 弹幕设置 → 弹幕 API 填 miniapp://com.logvar.danmu.node，或直接复制上面的主地址
  2. 播放时会自动把服务拉起来，不需要手动打开这个页面
  3. 要手动看状态：小程序详情页 → 「Node 服务」区块

这个包在做什么

弹幕服务本体跑在宿主的内嵌 node 里（worker_threads），不在本页面里。 配置写在包内的 server/index.config.js。
